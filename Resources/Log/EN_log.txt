# Version beta-0.7.0

### CHANGE LOG

**[ NEW: FRAME BOOSTER ]**
- **[5] in the Main Menu:** One click for max FPS (EN / FR). Safe and reversible.
    - Power plan "GAMING TWEAKS Ultimate": CPU 100%, no core parking, no USB/PCIe sleep.
    - Game Mode, Hardware-accelerated GPU scheduling, Optimizations for windowed games.
    - Games get high CPU, GPU and disk priority (MMCSS), foreground boost, no power throttling.
    - Background game recording off, precise game timer (Windows 11).
- **Restore:** 000 and My PC Backup undo every Frame Booster tweak. Older PC backups get the new settings added automatically.

**[ FIXES ]**
- **FIXED:** MSI Utility, TCP Optimizer, Filter Keys Setter, info pictures and View Log did not open (%RES% was never set).
- **FIXED:** Launcher now asks for Administrator rights by itself.
- **FIXED:** Boost CPU set GPU Priority to 0 on Intel and limited the boot CPU count: now it gives games high priority.
- **FIXED:** Boost RAM skipped PCs with 5-7 GB RAM: now it uses your exact RAM size.
- **FIXED:** Disable FSO set the wrong value (0): FSO is really disabled now, and Game Bar too.
- **FIXED:** "Disable Automatic App Updates" turned off all Windows Updates: now it only stops Microsoft Store app updates.
- **FIXED:** "Prevent Apps Auto Starting" did the same as Background Apps: now it opens Startup Apps.
- **FIXED:** Disable Spectre/Meltdown missed FeatureSettingsOverrideMask; it now warns and asks first.
- **FIXED:** French menu was missing some tweaks of the English menu.
- **NEW:** Restore options for Services and Memory Compression, mouse acceleration off, faster keyboard repeat.

# Version beta-0.5.7 (Dual Edition)

### CHANGE LOG

**[ COMMON CORE FEATURES ]**
- **Rewritten Core Logic:** Replaced all deprecated `WMIC` commands with `PowerShell` (Full Windows 11 24H2 Support).
- **Smart Hardware Detection:**
    - Auto-Detect RAM Size (Logic calculates bytes to GB automatically).
    - Auto-Detect CPU Logical Cores (No manual input required).
- **Native Multi-Language Support:**
    - Separated Core scripts into `Core_EN` and `Core_FR`.
    - Implemented UTF-8 Encoding to fix special character display errors.
- **Silent System Protection:** Automatically creates a Restore Point in the background using PowerShell execution policies.

**[ EDITION SPECIFIC: CLOUD ]**
- **Lightweight Architecture:** Single executable batch file (Launcher).
- **GitHub Integration:** Fetches the latest Core Scripts directly from the repository.
- **On-Demand Resources:** Downloads external tools (MSI Utility, TCP Optimizer) to `%TEMP%` only when requested via `curl`.

**[ EDITION SPECIFIC: LOCAL ]**
- **Offline Stability:** Fully functional without an internet connection.
- **Structured Resources:** Organized file hierarchy (`\Resources\Lang`, `\Resources\Tools`).

**[ FIXES ]**
- **FIXED:** "Command not found" errors related to WMIC removal in newer Windows builds.
- **FIXED:** Language Parsing bugs (Script now reads System Values instead of Localized Text strings).
- **FIXED:** Relative Path issues; script now functions correctly from any directory (USB/Desktop).
