# Version beta-0.5.7 (Dual Edition)

### CHANGE LOG

**[ COMMON CORE FEATURES ]**
- **Rewritten Core Logic:** Replaced all deprecated `WMIC` commands with `PowerShell` (Full Windows 11 24H2 Support).
- **Smart Hardware Detection:**
    - Auto-Detect RAM Size (Logic calculates bytes to GB automatically).
    - Auto-Detect CPU Logical Cores (No manual input required).
- **Native Multi-Language Support:**
    - Separated Core scripts into `Core_EN` and `Core_FR`.
    - Implemented UTF-8 Encoding to fix special character display errors.
- **Silent System Protection:** Automatically creates a Restore Point in the background using PowerShell execution policies.

**[ EDITION SPECIFIC: CLOUD ]**
- **Lightweight Architecture:** Single executable batch file (Launcher).
- **GitHub Integration:** Fetches the latest Core Scripts directly from the repository.
- **On-Demand Resources:** Downloads external tools (MSI Utility, TCP Optimizer) to `%TEMP%` only when requested via `curl`.

**[ EDITION SPECIFIC: LOCAL ]**
- **Offline Stability:** Fully functional without an internet connection.
- **Structured Resources:** Organized file hierarchy (`\Resources\Lang`, `\Resources\Tools`).

**[ FIXES ]**
- **FIXED:** "Command not found" errors related to WMIC removal in newer Windows builds.
- **FIXED:** Language Parsing bugs (Script now reads System Values instead of Localized Text strings).
- **FIXED:** Relative Path issues; script now functions correctly from any directory (USB/Desktop).
